# Slider

Numeric slider for compact value selection with keyboard support, click/drag interaction, and an optional inline value readout.

#### Example

<Canvas of={SliderStories.Default} />

## Usage

```tsx
import { useState } from "react";
import "react-magic-ui/style.css";
import { Slider } from "react-magic-ui";

const Example = () => {
  const [value, setValue] = useState(50);

  return (
    <Slider
      aria-label="Volume"
      min={0}
      max={100}
      step={5}
      value={value}
      onChange={setValue}
      showValue
    />
  );
};

export default Example;
```

## Props

- **value** — Controlled value for the slider thumb position.
- **onChange** — Called with the next numeric value after click, drag, or keyboard interaction.
- **min** / **max** — Range bounds. If `max` is lower than `min`, the component safely clamps to the minimum range.
- **step** — Increment size for keyboard and pointer updates. Non-positive values fall back to `1`.
- **size** — Visual size preset: `"small"`, `"medium"`, or `"large"`.
- **showValue** — Displays the current numeric value next to the slider.
- **disabled** — Prevents focus and interaction.
- **enableClickAnimation** — Reserved for the visual click treatment used by the component family.

## Behavior notes

- The slider exposes `role="slider"` with `aria-valuemin`, `aria-valuemax`, and `aria-valuenow` so assistive tech gets the current value.
- Keyboard users can adjust the value with `Arrow` keys, jump with `PageUp` / `PageDown`, and move directly to bounds with `Home` / `End`.
- Add `aria-label`, `aria-labelledby`, or `aria-valuetext` when the surrounding UI does not already make the control's meaning obvious.
- `Slider` is controlled today: keep the current value in parent state and update it in `onChange`.
