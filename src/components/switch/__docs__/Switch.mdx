# Switch

Glass-styled on/off switch for immediate setting changes, with optional label text and liquid click feedback.

## Example

<Canvas of={Switch.Default} />

## Usage

```tsx
import { useState } from "react";
import "react-magic-ui/style.css";
import { Switch } from "react-magic-ui";

export const Example = () => {
  const [isActive, setIsActive] = useState(false);

  return (
    <Switch
      isActive={isActive}
      setIsActive={setIsActive}
      label="Enable updates"
      size="medium"
    />
  );
};
```

## Behavior notes

- `Switch` renders with `role="switch"`, `aria-checked`, and `aria-disabled` so assistive tech announces it as a binary on/off control instead of a generic button
- when you pass `label`, the label is linked with `aria-labelledby`, and clicking the text toggles the switch too
- `setIsActive` receives the next boolean state after interaction, which makes the component straightforward to control from parent state
- disabled switches remain visible but ignore interaction
- set `enableClickAnimation={false}` if you want a quieter presentation without the liquid click effect

## Props

- **isActive** _(`boolean`)_ - current switch state for controlled usage
- **setIsActive** _(`(isActive: boolean) => void`)_ - called with the next state after a user toggle
- **label** _(`string`)_ - optional visible label rendered next to the switch
- **size** _(`"small" | "medium" | "large"`)_ - adjusts the switch dimensions
- **disabled** _(`boolean`)_ - prevents toggling and exposes disabled semantics to assistive tech
- **enableClickAnimation** _(`boolean`)_ - enables or disables the liquid click animation
- **Glass props** - passthrough styling/customization props from the shared `Glass` primitive
