# Card

`Card` is a flexible content container built on top of `Glass`. Use it when you want the library's visual shell plus simple layout controls for stacking or aligning content.

## Example

<Canvas of={Card.Default} />

## Usage

```tsx
import "react-magic-ui/style.css";
import { Card } from "react-magic-ui";

export function Example() {
  return (
    <Card size="medium" direction="column" align="start" justify="start">
      <h2>Project status</h2>
      <p>Everything important at a glance.</p>
    </Card>
  );
}
```

## Props

- **children** _`React.ReactNode`_ — Card content.
- **size** _`"small" | "medium" | "large"`_ — Controls padding and overall density.
- **direction** _`"column" | "row"`_ — Controls layout flow inside the card.
- **align** _`"center" | "start" | "end"`_ — Cross-axis alignment.
- **justify** _`"center" | "start" | "end" | "space-between" | "space-around"`_ — Main-axis distribution.
- **className** _`string`_ — Additional classes for the content wrapper.
- `Card` also accepts the shared `Glass` container props like **rootClassName** and **rootStyle**, plus standard HTML `div` attributes.

## Behavior notes

- `Card` is mostly presentational; it does not add landmark or interactive semantics on its own.
- If the card acts like a section, article, or clickable surface, provide the appropriate element/ARIA semantics yourself.
- Because it inherits from `Glass`, visual styling stays consistent with other library primitives.

## Good fits

- Dashboard summary panels
- Settings groups
- Marketing blocks or feature callouts
- Lightweight wrappers around form sections
