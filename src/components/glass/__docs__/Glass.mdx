# Glass

`Glass` is the visual foundation of the library: a polymorphic glass-morphism wrapper with optional liquid ripple animation.

## Example

<Canvas of={GlassStories.Default} />

## Usage

```tsx
import "react-magic-ui/style.css";
import { Glass } from "react-magic-ui";

export function Example() {
  return (
    <Glass>
      <h2>Glass effect content</h2>
      <p>Beautiful glass morphism design.</p>
    </Glass>
  );
}
```

## Core features

- **Glass morphism shell** — frosted background, highlight, and blur layers.
- **Optional liquid animation** — click-triggered ripple effect.
- **Programmatic animation** — trigger a centered ripple with `triggerAnimation`.
- **Polymorphic rendering** — render as any element with the `as` prop.
- **Container customization** — style the outer shell separately from the content node.

## Props

- **as** _`ElementType`_ — Element to render for the interactive/content node. Defaults to `"div"`.
- **children** _`React.ReactNode`_ — Content rendered inside the glass wrapper.
- **className** _`string`_ — Classes applied to the inner rendered element.
- **rootClassName** _`string`_ — Classes applied to the outer glass container.
- **rootStyle** _`React.CSSProperties`_ — Inline styles for the outer glass container.
- **enableLiquidAnimation** _`boolean`_ — Enables click-based ripple animation. Defaults to `false`.
- **triggerAnimation** _`boolean`_ — Starts a centered ripple when toggled to `true`.
- Native props for the chosen `as` element, including `onClick`, `aria-*`, and other HTML attributes, are forwarded.

## Behavior notes

- `Glass` is visual first. It does **not** automatically make a surface accessible or interactive — choose a semantic `as` value like `button` or `section` when that matters.
- If you render `as="button"`, provide the same accessibility treatment you would for any normal button, including an accessible name when needed.
- The outer shell and inner content are separate on purpose: use `rootClassName` / `rootStyle` for shell-level layout and `className` for content-level styling.

## CSS variables

You can tune the default visual treatment with CSS variables:

```css
:root {
  --lg-bg-color: rgba(255, 255, 255, 0.1);
  --lg-highlight: rgba(255, 255, 255, 0.25);
  --lg-text: #ffffff;
  --lg-hover-glow: rgba(255, 255, 255, 0.2);
}
```

## Best practices

1. Use it on colorful, textured, or gradient backgrounds where the glass treatment can actually read.
2. Keep text contrast high enough to stay readable through the blur/transparency effect.
3. Use liquid animation selectively — it looks nice, but too many animated surfaces get noisy fast.
4. Prefer semantic elements via `as` instead of bolting on click handlers to anonymous `div`s.
