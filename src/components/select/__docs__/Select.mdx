# Select

Select is a styled single-value combobox for short option lists.

#### Example

<Canvas of={Select.Default}/>

## a11y + behavior notes

- `Select` exposes combobox/listbox semantics and supports keyboard selection with `ArrowUp`, `ArrowDown`, `Home`, `End`, `Enter`, `Space`, and `Escape`
- focus returns to the trigger after choosing an option, so it behaves more like a real form control than a floating menu
- keep option labels short and distinct; this component is best for curated lists, not long searchable datasets

## Usage

```ts
import "react-magic-ui/style.css";
import {Select} from "react-magic-ui";
import { useState } from "react";

const Example = () => {
  const [value, setValue] = useState("");

  const options = [
    { value: "option1", label: "Option 1" },
    { value: "option2", label: "Option 2" },
    { value: "option3", label: "Option 3" },
  ];

  return (
      <Select
        size={"medium"}
        disabled={false}
        options={options}
        value={value}
        onChange={setValue}
        placeholder="Select an option"
        enableClickAnimation={true}
      />
  );
};

export default Example;
```

#### Props

- **options** _`{ value: string; label: string }[]`_ — The selectable options rendered in the listbox.
- **value** _`string`_ — Currently selected option value.
- **onChange** _`(value: string) => void`_ — Called with the next selected value.
- **placeholder** _`string`_ — Text shown when no value is selected. Defaults to `"Select an option"`.
- **size** _`"small" | "medium" | "large"`_ — Control height and spacing.
- **disabled** _`boolean`_ — Prevents opening, keyboard navigation, and selection.
- **enableClickAnimation** _`boolean`_ — Enables the glass click animation on the trigger. Default is `true`.
