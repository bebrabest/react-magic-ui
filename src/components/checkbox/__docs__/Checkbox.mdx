# Checkbox

Glass-styled checkbox control for binary choices, with optional label text and liquid click feedback.

## Example

<Canvas of={Checkbox.Default} />

## Usage

```tsx
import { useState } from "react";
import "react-magic-ui/style.css";
import { Checkbox } from "react-magic-ui";

export const Example = () => {
  const [checked, setChecked] = useState(false);

  return (
    <Checkbox
      checked={checked}
      onChange={setChecked}
      label="Check me"
      size="medium"
    />
  );
};
```

## Behavior notes

- `Checkbox` renders as a real button-backed control with `role="checkbox"`, `aria-checked`, and `aria-disabled`
- when you pass `label`, the text is linked to the control with `aria-labelledby`, and clicking the label toggles the checkbox too
- `onChange` receives the next boolean state, so the component works cleanly in controlled React flows
- disabled checkboxes stay visible but ignore interaction
- the liquid click effect is optional and can be disabled with `enableClickAnimation={false}`

## Props

- **checked** _(`boolean`)_ - current checked state for controlled usage
- **onChange** _(`(checked: boolean) => void`)_ - called with the next checked state after a user toggle
- **label** _(`string`)_ - optional visible label rendered next to the control
- **size** _(`"small" | "medium" | "large"`)_ - adjusts the checkbox dimensions
- **disabled** _(`boolean`)_ - prevents toggling and exposes disabled semantics to assistive tech
- **enableClickAnimation** _(`boolean`)_ - enables or disables the liquid click animation
- **Glass props** - passthrough styling/customization props from the shared `Glass` primitive
