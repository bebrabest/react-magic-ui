# Button

`Button` is the opinionated action primitive in `react-magic-ui`: glass styling by default, optional click animation, and native button behavior underneath.

## Example

<Canvas of={Button.Default} />

## Usage

```tsx
import "react-magic-ui/style.css";
import { Button } from "react-magic-ui";

export function Example() {
  return (
    <Button type="submit" variant="positive" size="medium">
      Save changes
    </Button>
  );
}
```

## Props

- **children** _`React.ReactNode`_ — Preferred button content. If both `children` and `text` are provided, `children` wins.
- **text** _`string`_ — Convenience text prop for simple buttons.
- **variant** _`"default" | "positive" | "negative" | "warning"`_ — Visual color treatment.
- **size** _`"small" | "medium" | "large"`_ — Control height and padding.
- **type** _`"button" | "submit" | "reset"`_ — Preserved and forwarded to the native button element. Defaults to `"button"`.
- **disabled** _`boolean`_ — Disables interaction and click animation.
- **rounded** _`boolean`_ — Renders the button with the rounded/circular treatment.
- **enableClickAnimation** _`boolean`_ — Enables the liquid click animation. Defaults to `true`.
- **className** _`string`_ — Additional classes applied to the interactive button element.
- **rootClassName / rootStyle** — Glass container customization inherited from `Glass`.
- Any other native button props like `aria-*`, `name`, or `value` are forwarded.

## Behavior notes

- `Button` renders a real `<button>`, so it works with forms, keyboard activation, and standard button semantics.
- Use `type="submit"` or `type="reset"` when the button lives inside a form — the component no longer forces everything to `type="button"`.
- For icon-only actions, add an accessible name with `aria-label`.

## When to use it

- Primary and secondary page actions
- Form submit/reset controls
- Toolbar or card actions where the glass visual style should stay consistent
