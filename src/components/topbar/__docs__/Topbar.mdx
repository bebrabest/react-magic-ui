# Topbar

Glass navigation shell for app headers, dashboards, and command surfaces. It exposes a compound API so you can mix brand content, flexible layout sections, and grouped actions without rebuilding the frame each time.

## Usage

```tsx
import "react-magic-ui/style.css";
import { Button, Input, Topbar } from "react-magic-ui";

export const Example = () => (
  <Topbar size="comfortable">
    <Topbar.Brand icon="✨" title="Magic UI" subtitle="Command Center" />

    <Topbar.Section grow>
      <Input size="medium" placeholder="Search anything..." />
    </Topbar.Section>

    <Topbar.Actions aria-label="Workspace actions">
      <Topbar.Divider />
      <Button text="Invite" size="small" />
      <Button text="Share" size="small" variant="link" />
    </Topbar.Actions>
  </Topbar>
);
```

## Composition notes

- `Topbar` renders through the shared `Glass` primitive and forwards normal header props, so you can treat it like a stylized `<header>` with extra layout helpers
- `Topbar.Section` handles alignment, spacing, wrapping, and optional growth - use it for search, breadcrumbs, navigation, filters, or any flexible middle area
- `Topbar.Brand` adapts its icon sizing to the active topbar size and can either render `icon` / `title` / `subtitle` props or fully custom children
- `Topbar.Actions` is right-aligned by default and automatically adds `role="group"` when you provide `aria-label`, `aria-labelledby`, or `aria-describedby`, which is useful for clusters of icon buttons
- `Topbar.Divider` is decorative and already marked `aria-hidden`
- `Topbar.useTopbar()` lets compound children read the active sizing context, and throws if used outside `Topbar`

## API

- **Topbar** _(`{ size?, elevated? } & header props & Glass props`)_ - root container; `size` controls density and `elevated` toggles the shadow treatment
- **Topbar.Section** _(`{ grow?, align?, gap?, wrap? }`)_ - flexible layout region with alignment and spacing helpers
- **Topbar.Brand** _(`{ icon?, title?, subtitle?, iconClassName? }`)_ - brand helper for standard product/title treatment, or a hook point for custom children
- **Topbar.Actions** _(`{ gap? } & div props`)_ - action cluster aligned to the right edge; gains accessible grouping semantics when labeled
- **Topbar.Divider** _(`div props`)_ - responsive separator sized to the current topbar density
- **Topbar.useTopbar()** _(() => `{ size: "compact" | "comfortable" | "spacious" }`)_ - access the active topbar sizing context inside compound children
